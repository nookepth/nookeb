# 🐭 หนูเก็บ Task Workspace — ระบบตามงานครบวงจรใน Google Sheets

อัปเกรดสเปรดชีต **"หนูเก็บ — งานของฉัน"** (ที่ระบบ sync ของหนูเก็บสร้างให้) ให้เป็น
workspace ระดับ Notion/Asana/Linear ทั้งหมดภายใน Google Sheets — 9 ชีตทำงานเชื่อมกัน
ผ่านสูตร + Apps Script โดย **ไม่ทำให้ Google Sheets sync ของหนูเก็บพัง**

---

## ⚠️ สัญญากับระบบ sync ของหนูเก็บ (อ่านก่อนแก้อะไรทั้งนั้น)

ระบบนี้ออกแบบรอบข้อจำกัดจริงของ `sheetsWorker` / `google-sheets.service.ts`:

| ข้อเท็จจริงของ sync | ผลต่อการออกแบบ |
|---|---|
| sync เป็นเจ้าของ **คอลัมน์ A–J** ของแท็บ `งานของฉัน` — เขียนค่าทับ + ทาสีพื้นทั้ง A–J ทุกครั้งที่งานเปลี่ยน | ทุกฟีเจอร์เสริมอยู่ **คอลัมน์ K เป็นต้นไป** หรือชีตอื่น · CF บน A–J ใช้เฉพาะ**สีตัวอักษร** (คอลัมน์ E) ไม่ใช้สีพื้น |
| sync หาแถวด้วย **คอลัมน์ J `รหัสงาน`** (ซ่อนอยู่) | **ห้ามลบ/ย้าย/แก้คอลัมน์ J เด็ดขาด** · เรียงแถวได้ (ทั้งแถวเลื่อนพร้อมกัน sync ไม่หลง) |
| วันที่มาเป็น **ข้อความ** `DD/MM/YYYY HH:mm` (เวลาไทย) ไม่ใช่ date จริง | ชีต `_CALC` แปลงเป็น date จริงให้ทุก view ใช้ |
| การเขียนผ่าน Sheets API **ไม่ยิง onEdit** | ใช้ **onChange + สแนปช็อต (`_SNAPSHOT`)** เทียบหาสถานะที่เปลี่ยน |
| sync เป็น**ทางเดียว**: หนูเก็บ → ชีต | งานที่สร้างจากฟอร์ม 📋 อยู่ในชีตเท่านั้น (รหัส `LOCAL-…` — sync ไม่รู้จักจึงไม่ทับ) **ไม่ส่งเข้า LINE** |
| สถานะเป็นภาษาไทยตายตัว: รอดำเนินการ / กำลังทำ / รอตรวจ / เสร็จแล้ว / ตีกลับ / ยกเลิก / ลบแล้ว | dropdown ทุกจุดใช้ชุดคำนี้เป๊ะ ๆ |

ข้อจำกัดที่ยอมรับโดยแจ้งไว้ตรง ๆ:
- "รับงานแล้วหรือยัง" (accepted_at) ไม่ถูก sync มาที่ชีต — รายงานทีมใช้สถานะ
  `กำลังทำ` เป็นตัวแทน, `รอตรวจ` = ส่งงานกลับแล้ว, `ตีกลับ` = โดนตีกลับ
- เหตุผลตีกลับจริงอยู่ใน LINE/แอป — ชีตมีช่อง 📝 หมายเหตุ ให้จดเอง
- มาโครเรียงตาราง (เมนู ↕️) เขียนแถวใหม่ทั้งตาราง — ถ้า sync เขียนแทรก
  เสี้ยววินาทีเดียวกันอาจเห็นแถวซ้ำชั่วคราว รอบ sync ถัดไปซ่อมตัวเอง

## 🚀 ติดตั้ง (5 นาที)

1. เปิดสเปรดชีต **"หนูเก็บ — งานของฉัน"** → เมนู **Extensions → Apps Script**
2. ลบไฟล์ `Code.gs` เดิม แล้วสร้างไฟล์ตามชื่อในโฟลเดอร์นี้ (`00_config` … `09_weekly`)
   คัดลอกเนื้อหาไฟล์ต่อไฟล์ (นามสกุลใน editor เป็น `.gs` อัตโนมัติ)
3. กด 💾 บันทึก → กลับมาที่สเปรดชีต → รีโหลดหน้า (F5)
4. เมนูใหม่ **🐭 หนูเก็บ** จะโผล่ → กด **🛠️ ติดตั้ง/ซ่อมระบบทั้งหมด**
   (ครั้งแรก Google ถามสิทธิ์ → Allow)
5. กด **⚡ ติดตั้งทริกเกอร์อัตโนมัติ** (ครั้งเดียว) — ได้ onChange + ตรวจรายวัน 07:00 + สรุปจันทร์ 08:00
6. **สำคัญ:** File → Settings → Calculation → **Recalculation: On change and every minute**
   (ให้เวลา/นับถอยหลังบนหน้าหลักเดินเอง)

รันซ้ำได้ทุกเมื่อ — `setupWorkspace` สร้างเฉพาะชีตของระบบใหม่ ไม่แตะข้อมูลงาน
และไม่ล้าง `_SNAPSHOT` (ประวัติสะสมสำหรับกราฟแนวโน้ม)

## ⚙️ ระบบอัตโนมัติ

| ทริกเกอร์ | ทำอะไร |
|---|---|
| `onChange` (จับได้ทั้งคนแก้และ sync เขียน) | engine เทียบสแนปช็อต → ต่อบรรทัด 🕐 ประวัติสถานะ, ประทับเวลาเปลี่ยนสถานะ (ฐานตัวจับคอขวด), จำวัน "เห็นครั้งแรก/เสร็จเมื่อ" (ฐานกราฟแนวโน้ม), แจกรหัส LOCAL + สถานะ/เวลาให้แถวที่พิมพ์เพิ่มเอง, เติมความด่วนเริ่มต้น 🟡 (กันถี่: สูงสุด 1 ครั้ง/20 วิ) |
| `onEdit` (คนแก้เอง) | ปุ่มความด่วน/ปุ่มส่งในฟอร์ม, ◀ ▶ ปฏิทิน, log ทันทีเมื่อแก้สถานะเองในตาราง |
| รายวัน 07:00 | งานเกินกำหนดที่ยังไม่จบ → 🔔 เตือนครั้งที่ +1 (วันละครั้ง/งาน) + จด log + เก็บสถิติรายวัน + รีเฟรชวิเคราะห์/รายชื่อคน |
| จันทร์ 08:00 | สร้างบล็อกสรุปสัปดาห์ใหม่บนสุดของ 📅 |

เมนู 🐭 มีปุ่ม: รีเฟรชหน้าหลัก+กราฟ · วาดปฏิทิน · รีเฟรชวิเคราะห์ · สรุปสัปดาห์ทันที ·
ตรวจงานเกินกำหนดทันที · เรียงตาราง (กำหนดส่ง/ความด่วน/ผู้รับ)

## 🧠 ของแถมที่ใส่ให้เกินโจทย์ (และเหตุผล)

- **ตัวจับคอขวด** — งานค้างสถานะเดิมเกิน 3 วันขึ้นป้าย ⚠️ ใน ⚡/สรุปสัปดาห์
  (ใช้เวลาเปลี่ยนสถานะจริงจากสแนปช็อต ไม่ใช่เดา)
- **"เห็นครั้งแรก/เสร็จเมื่อ"** — ชีตจาก sync ไม่มีวันที่สร้างงาน ระบบจึงจำเองตั้งแต่วันติดตั้ง
  → ได้กราฟงานเข้า/อัตราเสร็จ/ความเร็วรายคนแบบตรงไปตรงมา (สะสมยิ่งนานยิ่งแม่น)
- **มิเตอร์ `▓▓▓▓░` + สายพาน `●━●━◐┄○┄○`** — สแกนด้วยตาเร็วกว่าอ่านคำ
- **ประวัติรายวัน** (ค้าง/เกินกำหนด) → กราฟแนวโน้มเกินกำหนดที่ระบบ BI จริงมีกัน
- **ดาวประจำสัปดาห์ + ใครเร็ว/ช้า** — สร้างแรงจูงใจทีมโดยไม่ต้องเปิดแอปอื่น
- **แถวเพิ่มเองในตารางก็ไม่หลุดระบบ** — engine แจกรหัส/สถานะ/log ให้อัตโนมัติ

## 📌 Named ranges / สูตรหลัก / CF (อ้างอิงเร็ว)

- Named ranges (สคริปต์สร้างให้): `People`, `TypeList`, `StatusList`, `UrgencyList`, `MasterTaskIds`, `CalcTable`
- ตัวแปลงวันที่ (หัวใจของทุกอย่าง, `_CALC!E`):
  `MAP(D2:D, LAMBDA(v, IF(ISNUMBER(v), v, DATE(MID(v,7,4), MID(v,4,2), LEFT(v,2)) + TIME(MID(v,12,2), MID(v,15,2), 0))))`
- ธงเกินกำหนด (`_CALC!O`): มี deadline ∧ เลยเวลา ∧ สถานะ ∈ {รอดำเนินการ, กำลังทำ, รอตรวจ, ตีกลับ}
- ทุก view ใช้แพตเทิร์นเดียว: `ARRAY_CONSTRAIN(SORT(FILTER({_CALC!…}, เงื่อนไข), คีย์, …), แถว, คอลัมน์)`
  (คีย์เรียงซ่อนไว้เป็นคอลัมน์ท้ายแล้วตัดทิ้งด้วย ARRAY_CONSTRAIN)
- CF บน master: E แดงหนาเมื่อเกินกำหนด (ผ่าน VLOOKUP+INDIRECT ไป `_CALC`), K พื้นอ่อน 4 ระดับ, L แดงเมื่อเตือน ≥ 3
- CF บน views: แถวแดง/ส้มตามระดับ, gradient heatmap ภาระงาน (ขาว→ส้ม→แดง) และ % สำเร็จ (แดง→เหลือง→เขียว)
